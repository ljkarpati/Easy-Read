# EasyRead

EasyRead makes reading more comfortable. Paste, type or open some text, and EasyRead shows it in a calm, dyslexia-friendly layout. It can also read the text aloud and highlight each sentence as it goes.

It is for people with dyslexia and other reading difficulties, and for anyone with tired eyes or reading in a second language.

## Status

Early build. Phase 0 (setup) is done. The full plan is in `CLAUDE.md`.

## Privacy

Your text never leaves this device. EasyRead has no accounts, no analytics, no tracking and no server.

## Run it on your computer

You need the free [Node.js LTS](https://nodejs.org) and [Git](https://git-scm.com).

In PowerShell:

```powershell
git clone https://github.com/ljkarpati/Easy-Read.git
cd Easy-Read
npx serve .
```

Then open the address it prints, usually http://localhost:3000.

## How it's built

Plain HTML, CSS and JavaScript. There are no frameworks and no build step, so the folder works as-is on any static host.

This is a practice build. Claude Code wrote the code.
